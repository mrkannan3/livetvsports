# LiveTV Sports Kodi Addon Repository

This repository contains the **LiveTV Sports** addon for Kodi.

## Installation Instructions

1.  Open Kodi.
2.  Go to **Settings** (gear icon) > **File Manager**.
3.  Select **Add source**.
4.  Enter the following URL: `https://raw.githubusercontent.com/username/livetv-sports-repo/master/`
5.  Enter a name for this source (e.g., `LiveTV Repo`) and click **OK**.
6.  Go back to the home screen and select **Add-ons**.
7.  Click the **Add-on browser** icon (open box) in the top left.
8.  Select **Install from zip file**. (If prompted, enable "Unknown sources" in settings).
9.  Select the source you named in step 5 (`LiveTV Repo`).
10. Select `repository.livetvsports-1.0.0.zip`.
11. Wait for the notification that the repository is installed.
12. Select **Install from repository**.
13. Select **LiveTV Sports Repository**.
14. Select **Video add-ons** > **LiveTV Sports**.
15. Select **Install**.
